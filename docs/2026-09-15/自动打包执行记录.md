## Intent：最终目标

交付 `build` 分支自动打包和 GitHub Actions 手动打包能力。

## Data：可用证据

- 工作流包含 `push.branches: [build]` 和 `workflow_dispatch`，只有仓库读取权限。
- 两个平台分别执行现有 ggml bootstrap、ReleaseSmall 构建和 GGUF 导出。
- 二进制包包含模型、配置、元数据、提交号、说明和许可证，通过 tar 保存执行权限。

- 没有新增测试用例，没有调用浏览器确认 UI。
- 云端启动验证覆盖 GitHub 托管的 Ubuntu 24.04 x86_64 和 macOS 15 Apple Silicon，不代表所有操作系统版本均兼容。
