# 执行记录

## Intent：最终目标

执行既定方案。先验证 Zig 训练与内嵌二进制，再推进数据采集和布局模型。用户随后明确不强求 ONNX，因此主路线采用原生权重和 Zig 推理。

当前第一版已完成构建、训练、zgpu 接入和 20 组测试。结果与不足见[训练与测试结果](./训练与测试结果.md)；泛化质量仍不均衡，尚未达到完整、精确排版器的目标。

核心审美：**代码如诗，不仅要好读，还要好看。** 用户偏向疏朗的分段；相关语句保持紧凑，转折和阶段边界留白，不以机械空行密度作为目标。

六种语言只是首批来源，不能成为产品白名单。共享 Tokenizer 不识别语言名，特征中不包含语言或仓库。另设整门语言未见过的评估来源。

## Data：已知证据

- 2026-09-10，本机为 macOS arm64，32 GiB 内存，Zig 0.16.0。
- CMake、Ninja 和 Apple Clang 可用。
- 当前无产品实现，计划文档已存在。
- ONNX Runtime 最小构建不支持原始 ONNX 加载，不能直接用于最终要求。

## Edges：阶段边界

- 第一阶段使用合成分类数据验证训练数学和格式互通，不宣称具备代码分段能力。
- 训练和模型导出使用 Zig；ONNX Runtime 的上游构建工具仅用于构建第三方库。
- 合成可行性实验通过后才能开始 18 个语料仓库的采集。
- 原生权重明确命名为 `.weights`；ONNX 导出仅为可选实验，不宣称已通过第三方运行时验证。

## Answer：本阶段验收

1. 梯度数值检查通过，训练损失下降，独立合成验证集表现明显优于随机。
2. Zig 写出的原生权重可由独立程序从内存加载。
3. 相同输入的训练前向输出和独立程序输出误差符合门槛。
4. 模型内嵌，复制单个程序到独立目录后能运行，无第三方推理库。

## 进展

- 已完成合成实验：8 输入、16 隐层、3 输出，共 195 个参数；训练 2048 个样本，独立验证 1024 个样本，150 epoch。
- 全参数有限差分梯度检查最大绝对误差：0.00009471。
- 训练损失从 1.18692580 降到 0.03452668，独立合成验证准确率 0.98339844。
- 原生权重 832 字节；257 组独立输入在嵌入推理端最大绝对误差为 0。
- 将程序单独复制到新临时目录，用空环境运行成功；动态链接仅 `/usr/lib/libSystem.B.dylib`。
