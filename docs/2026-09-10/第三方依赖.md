# 第三方依赖

## Intent：复用成熟 GPU 接口

产品的 GPU 平台适配由 zgpu/Dawn 提供。项目只定义小模型的 WGSL 计算和调用流程，不实现 Metal、Vulkan 或 DX12 适配层。

## Data：版本与来源

| 依赖 | 固定来源 | 用途 |
| --- | --- | --- |
| zgpu | `e6d8103b3c34ce1d6aab4db86dedf9ac889b4e67` | Zig WebGPU 接口，MIT |
| Dawn macOS arm64 预编译包 | `d2360cdfff0cf4a780cb77aa47c57aca03cc6dfe` | 原生 WebGPU 实现 |
| zpool | `02d1472cc4c134a86ff31d19fb546cf478f6b988` | zgpu 的包依赖 |
| system_sdk | `c0dbf11cdc17da5904ea8a17eadc54dee26567ec` | 上游构建使用的系统 SDK |
| Tree-sitter 与语言语法 | `config/parsers.lock.json` | 仅离线检查，不进入产品 |

精确的包校验值见 `build.zig.zon`。上游来源：[zgpu](https://github.com/zig-gamedev/zgpu)、[Dawn](https://dawn.googlesource.com/dawn)、[Dawn 预编译包](https://github.com/michal-z/webgpu_dawn-aarch64-macos)、[zpool](https://github.com/zig-gamedev/zpool)、[system_sdk](https://github.com/zig-gamedev/system_sdk)。

## Edges：交付边界

当前程序静态链接 Dawn，动态依赖仅为 macOS 系统组件。其他平台的预编译包已在构建配置中按目标声明，但本次仅完成 macOS 实机验证。

依赖及语料保留各自的许可和来源；本项目许可证不替代它们的许可证。原始数据和实验缓存不加入源码版本库。

## Answer：复现入口

`zig build` 使用已锁定的包。`zig build bootstrap -Dgpu=false` 准备离线解析器，`--style` 则通过 gh 获取风格参考。当前环境曾遇到包下载的代理连接关闭错误，临时移除该进程的代理变量后完成下载，没有修改全局代理设置。
