# 推理后端选型

## Intent：最终目标

默认使用 GPU 执行模型。设备、后端或所需算子不可用时才回退 CPU，不因文件小或 CPU 更快而自动改用 CPU。

采用现成 C/Zig 接口库，避免自行实现 GPU 接入层。保留 Zig 主程序和内嵌模型的单文件交付。

**用户最终选择 zgpu，以通用性优先。** 后续采用 zgpu/Dawn 的设备与资源接口，模型本身用一个小型 WGSL 计算定义表达；不实现 Metal/Vulkan/DX12 适配层。此前 ggml 为候选建议，现不作为执行方案。

## Data：已核实证据

| 方案 | 接口与 GPU 能力 | 对本项目的适配判断 |
| --- | --- | --- |
| ggml | C API，已有矩阵/激活算子和 Metal 后端 | 候选备选，本次不采用 |
| MLX C | C API，现成 tensor 算子，可指定 GPU stream | 可行备选；标准构建仍需 metallib，单文件资源加载较复杂 |
| zgpu | Zig 包装 Dawn 原生 WebGPU，支持 Metal/Vulkan/DX12 | 用户选定；复用接入层，只实现固定模型的 WGSL 前向定义 |
| ZML | Zig、MLIR、Bazel 推理框架 | 范围比当前固定小模型大；所读公开支持表未确认 Metal 路线 |

来源：[ggml](https://github.com/ggml-org/ggml)、[ggml Metal 构建配置](https://github.com/ggml-org/ggml/blob/7840aaba1989c6deeefede1d77d5aaf8f52b947e/src/ggml-metal/CMakeLists.txt)、[MLX C v0.6.0](https://github.com/ml-explore/mlx-c/tree/v0.6.0)、[MLX v0.31.1 kernel 构建](https://github.com/ml-explore/mlx/blob/v0.31.1/mlx/backend/metal/kernels/CMakeLists.txt)、[zgpu](https://github.com/zig-gamedev/zgpu)、[ZML](https://github.com/zml/zml)。

zgpu 固定提交：`e6d8103b3c34ce1d6aab4db86dedf9ac889b4e67`，MIT 许可证。其包声明最低 Zig 0.15.2，需要在当前 Zig 0.16.0 上实测编译。使用现有 Dawn 原生预编译库和上游 SDK 依赖。

当前实际测试主机经 `sysctl` 核实为 **Apple M5、32 GiB 内存**。此前按附件 M4 进行规划，后续实测报告使用真实硬件信息。

## Edges：边界与限制

- 首次实测 macOS Metal；zgpu 的其他原生后端按平台选择，未适配目标明确报告回退原因。
- WGSL 实现同一固定 MLP 的矩阵、偏置与 ReLU，数值精度必须与 Zig CPU 参考实现比较。
- 初始目标为最大绝对误差不超过 1e-4，分类结果一致。
- Dawn/zgpu 静态链接，WGSL 与权重内嵌，不旁置 kernel 文件或第三方动态库。
- 引入成熟后端会增加完整程序体积；模型权重大小与程序大小分开报告。
- 不把检测到 GPU 当作推理成功，必须执行图、读取结果并记录实际 GPU 调用。
- 当前 Metal 命令行编译器不可执行；Dawn 使用系统运行时编译，已完成实际 GPU 验证。

实测结果：zgpu 在 Zig 0.16.0 下编译运行，1025 个输入全部由 Metal GPU 执行，与 CPU 最大绝对误差约 3.81e-6。链接时补充了 CoreFoundation 系统 framework，未修改上游 GPU 实现。具体结果见[训练与测试结果](./训练与测试结果.md)。

## Answer：交付与验收

1. 默认 GPU 的 Zig 程序，失败时显式 CPU 回退及原因。
2. GPU/CPU 数值对照，包括单样本、完整批次和尾批次。
3. CPU-only 构建验证无 GPU 后端时的回退路径。
4. 单文件复制运行检查，动态依赖清单只包含系统组件。

```mermaid
flowchart LR
    A[内嵌模型与通用特征] --> B[zgpu 硬件适配器初始化]
    B -->|可用且兼容| C[GPU 执行内嵌 WGSL]
    B -->|不可用| D[Zig CPU 前向]
    C -->|执行失败| D
    C --> E[置信度与布局补丁]
    D --> E
```

## 自我审查

复用成熟库降低了自写 GPU 层的维护风险，但不能省略实际运行验证。测试需要暴露 CPU 回退，避免“返回了正确结果”掩盖 GPU 从未执行。
