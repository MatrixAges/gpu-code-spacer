# 语句分组完善

## Intent：最终目标

落实用户明确的审美原则：同一层级不同类型的完整语句之间需要空行。重点包括声明到控制流程、声明到调用、其他语句到返回。通过新的 C# 案例验证跨语言效果。

## Data：可用证据

- 现有 TypeScript 实际输出遗漏上述边界。
- 现有模型使用通用词元哈希和行形状，训练标签来自原作者排版，无法保证新的明确风格约束。
- 当前产品已有词法保护与非空行字节保持校验，采用 zgpu 推理。

## Edges：边界与限制

- 不针对示例内容、变量名或扩展名编码；根据语句结构和类别判断。
- 用户进一步指出：这些原则已经存在于 `if` 中。因此必须检查学习链路，不能以规则后处理代替学会已有样本。
- 不新增强制留白规则；新增输入特征也不能直接决定输出标签。
- 只处理完整语句的边界，不拆开参数、链式调用、字符串与多行表达式。
- 不在块首的单独 return 前机械插空行。

## Answer：交付格式与成功标准

1. 审计真实样本、清洗标签、训练采样和特征表示，依据证据修复并重训。
2. C# 输入与实际输出文件，覆盖声明、调用、赋值、控制流程与返回。
3. 验证 C# 结构解析、非空行保持、幂等，以及既有词法保护。
4. 报告实际结果和未覆盖结构，不以示例通过代替泛化结论。

## 执行结果与自我批判

首次尝试加入语句类别强制分隔规则，被用户指出方向偏离后已撤回；不作为产品交付。继续审计学习链路。

### 真实语料审计

通过 ast-grep 的 TypeScript AST 识别相邻语句，并关联已接纳文件：

| 边界 | 无空行 | 空一行 |
|---|---:|---:|
| 声明 → if | 10 | 696 |
| 声明 → 直接调用或 await 调用 | 7 | 342 |
| 调用 → 声明 | 1 | 65 |
| if → 声明 | 2 | 314 |
| 有非注释前驱的 return | 16 | 569 |
| 声明 → 声明 | 807 | 296 |
| 调用 → 调用 | 247 | 254 |

结论：用户要求在参考语料中已有强信号；同类语句仍可能因阶段变化而分段，不能把分类差异当作完整审美定义。

`prepare` 保留原作者的 `boundary.blank_lines` 标签。`if` 实际风格训练保留 31,504 个边界，其中 4,793 个空行，主要信号没有被清洗掉。但两个图标数组分别贡献 5,774、5,374 个零空行边界，占全部个人风格训练 31,748 个边界的 35.11%。原训练按边界均匀采样，放大了这类数据表。

验证集 4,906 个边界没有这些图标数组；全零空行文件占 4.85%，最大十个业务文件占 44.74%。所以本轮先保留原验证数据，不因个案删除文件。

### 第一阶段：表示与采样

- 风格采样改成文件均匀，再在文件内均匀选边界。不按图标文件名排除数据。
- 特征 v4 保留原 128 维，新增 32 维共享表面角色和同缩进上下文。角色只进入模型，不直接指定空行；程序没有语句分组后处理。
- 特征与权重版本对应，重新生成全部特征，三个固定种子重训。
- 单独改变采样的 v3 对照验证分数 0.8910，低于原模型 0.8968。不能把“采样更均匀”直接宣称为质量提高。
- v4 表示与采样一起修正，按原目标选出 seed 111，分数 0.9031，置信度 0.70。
- 第一次冻结验收集 v1：旧模型 156/226，新模型 181/226；未见语言 78/110 → 92/110。36 个源案例各有紧凑、过疏两个变体，不是 72 个独立任务。
- 必须留白的位置只通过 60/100；声明到调用只有 10/26。总通过率不能掩盖主要求缺口。

### 第二阶段：对齐训练目标

用户强调核心是泛化质量与验收设计。通用仓库的原作者排版不等于个人审美真值，风格微调仍混入 50% 通用排版、选模奖励 30% 通用一致性，存在目标冲突。

本阶段预先限定候选：三个固定种子 × 风格采样比例 0.5 / 0.8 / 1.0，各最多 24 轮，仍使用开发训练和个人验证数据。通用预训练保留；最终选模只依照个人风格验证 macro-F1，精度 ≥95%、召回 ≥60% 的校准门槛保持不变。通用语言指标仍报告，但不再作为审美奖励。

v1 已经看过结果，后续只作回归检查，不再称为独立最终测试。另由独立步骤设计和冻结 v2 验收集，在最终权重与阈值确定之后运行；不按 v2 个案修改产品、模型或阈值。

最终选出 seed 111 / 100% 个人风格采样，置信度 0.80。新的独立最终集从旧模型 116/196 提升到 179/196；未见语言 65/96 → 89/96。三个主原则 112/118，但同类相关连续语句从 19/20 退步到 11/20，需明确保留这个局限。最终权重冻结后没有根据该集继续调参。完整结果、边界与复现见《泛化质量结果.md》。
