# 模型分组矫正执行记录

## Intent：最终目标

依靠模型训练修复用户指出的五类分组问题，同时保持与本次调整无关的正确留白。不得为演示添加硬编码识别，不得修改无关 evaluation 期望来制造通过率。

## Data：证据与根因

旧模型为 v6-2026-standard，192 维输入、64 个隐藏单元、12547 个参数，权重文件 50244 字节。此次保持这些结构以及推理源码不变。

- Python 属性到装饰器：原模型预测不留白概率约 72.54%。
- elif 边界：原模型预测不留白概率约 95.53%–99.69%。
- ncvalue 到累加初始化：原模型预测不留白概率约 99.96%。
- Zig 声明到赋值：同类边界的加空行概率因上下文在 31%–60% 间变化，用户指出位置仅约 48.92%。
- 旧选优指标只关注 TypeScript 风格验证集；六语言人工修订数据没有参与这一选优指标。
- 既有 Python 数据同时包含 elif 前留白与不留白的冲突标注。逐处核查 12 份实际源码后，将本次确认的 elif 标准统一；auth 中移除初始化与首次累加之间的空行。

## Edges：实验与证据边界

- 未修改 `src/`、网页演示输入和任何 evaluation 输入或期望。
- 未新增测试用例，未使用浏览器。
- 1414 份人工修订文件按内容哈希确定 138 份整文件验证集。早期全量训练按六语言、文件、边界均匀抽样；最终收窄到相关反馈文件并回放其他开发文件。文件来自相同上游仓库，不是仓库级完全独立验证。
- JavaScript 验证仅 1 个文件、64 个边界；单语言小样本分数的可信范围有限。
- 从旧模型继续训练时，留出的文件可能在旧训练中出现，因此继续训练的验证分数不宣称为完全独立泛化结果。
- Python 与 Zig 演示来源文件本就在训练数据中，修复它们只能说明反馈被学习。早期实验没有 Swift 训练数据；最终将用户指出的三个真实 Swift 函数人工标注后加入训练，因此不能再将它们称为未见语言泛化证据。
- 全部 evaluation 仅用于回归验收和开发反馈，不加入训练；反复观察过的回归不能称为未见测试。

### 自我批判

最初把特征识别缺口直接转化为新语法处理，并不符合用户要用模型获得泛化的方向，已经撤回。后续不能以验证宏 F1 上升抵消明确的无关回归；同样，调整评价资料的授权也不能被解释为允许让评价迎合预测。阶段候选均未晋升；仅在本次反馈和完整回归同时达标后替换默认模型。

## 最终实现与晋升结果

### 训练改动

- `tools/reviewed.zig`：按整文件内容哈希留出验证，读取显式反馈清单；清单文件仅供离线训练，运行时不会读取或匹配其中的文件路径。
- `tools/train.zig`：在旧权重上进行增量校准。95% 样本回放旧模型在其他开发文件上的概率分布，5% 使用人工反馈；保留既有正数空行计数，只学习反馈所要求的有无间隔。保存每轮检查点以便独立验收。
- `tools/learning/ggml.zig`：支持概率分布形式的训练目标，避免把旧模型原本不确定的判断强行变成极端的一热目标。仅影响训练，不修改推理。
- `tools/select_model.zig`：人工修订模型晋升必须提供既有完整回归报告；核对权重 SHA-256、置信度、完整匹配、内容保真和幂等性。真实失败候选已验证被 `RegressionGateFailed` 拦截，失败前后默认权重哈希一致。
- 人工反馈清单共 21 个来源，其中 2 份 Python 文件仍留在验证侧，实际监督训练为 19 个文件、6622 个边界。回放池为 401177 个开发边界，不包含 evaluation 或本轮留出的验证文件。
- 新增 Swift 反馈是现有演示里的三个完整函数；原代码与缩进保留，许可证和固定提交来源记录在 `dataset/feedback/README.md`。

### 复现命令

```sh
mkdir -p artifacts

git show 920cec4e6cce742f71d778b3a5f30b158ea4273a:models/spacer.weights > artifacts/v6-before-feedback.weights

zig build prepare -Doptimize=ReleaseFast

zig build train -Doptimize=ReleaseFast -- \
  --reviewed --feedback-files config/spacing-feedback.json --save-epochs \
  --seed 111 --epochs 32 --steps 2048 --learning-rate 0.0003 \
  --replay-share 0.95 --init artifacts/v6-before-feedback.weights \
  --output-prefix artifacts/v6-feedback-checkpoints-111

zig build -Doptimize=ReleaseFast -Dgpu=false \
  -Dmodel=artifacts/v6-feedback-checkpoints-111-epoch-4.weights \
  --prefix artifacts/feedback-final

python3 tools/evaluate_dataset.py artifacts/feedback-final/bin/gcs \
  evaluation/artifacts/feedback-final-reproduction

zig build select-model -Doptimize=ReleaseFast -- \
  artifacts/v6-feedback-checkpoints-111-epoch-4.json \
  --regression-report evaluation/artifacts/feedback-final-reproduction/report.json

npm run build:web
```

评估报告目录必须尚不存在。复现依赖本仓库锁定的原始训练材料；反馈来源清单和源码内容哈希在训练报告中记录。
